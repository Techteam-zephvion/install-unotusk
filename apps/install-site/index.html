3-Minute Quick Start Guide

STEP 1

Deploy Server Host

On your server or workstation, run the Server Setup Wizard. Click Deploy to start the database and backend services automatically.

STEP 2

Share Local IP

The wizard displays your LAN endpoint (e.g. http://10.0.0.59:8000). Copy and share it with your team.

STEP 3

Open Desktop Client

Team members launch the desktop app on their laptops, enter the IP, and begin querying the codebase with zero cloud egress.
