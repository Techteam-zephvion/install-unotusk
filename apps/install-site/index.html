Execution Order

Installation Procedure

Four-step operational sequence from bare host to active team querying.

Deploying Unotusk takes approximately 3 to 5 minutes on standard developer hardware.

Pre-requisites: Host machine requires Docker Engine or Docker Desktop installed and running. No public domain names or SSL certificates required for internal LAN use.

01 Deploy Host Server

Download and run the Server Setup Wizard on your host server or designated developer workstation. The wizard automatically pulls container images and boots PostgreSQL, Redis, and the FastAPI engine.

02 Verify Server Health

Execute the health endpoint check from the command line to confirm local containers are operational:

curl -s http://localhost:28000/api/v1/health
03 Share LAN Endpoint

Locate your host machine's internal network IP address (e.g. http://10.0.0.59:28000). Distribute this internal URL to team members.

04 Connect Desktop Clients

Engineers launch the Desktop Client on macOS, Windows, or Linux, paste the host endpoint into the connection field, and immediately begin querying repository intelligence.
