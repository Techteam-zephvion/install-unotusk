Frictionless Setup Runbook

3-minute deployment flow from zero to operational intelligence

STEP 1

Launch Wizard

Run the downloaded Server Application (.msi or .tar.gz). It executes pre-flight checks automatically.

STEP 2

Initialize Stack

Click Deploy. The wizard silently boots PostgreSQL 16 + pgvector, Redis, and FastAPI in Docker without touching your terminal.

STEP 3

Distribute Endpoint

The wizard outputs your local IP (e.g. http://10.0.0.59:8000). Share this address with your team members.
