Installation Instructions

1. If you are the Administrator, download and install the Server Application. The wizard will automatically handle downloading backend images and setting up the database.

2. If you are an employee, download the Employee Application for your specific Operating System.

3. On launch, the Employee Application will prompt you for the internal IP address provided by your Administrator.
