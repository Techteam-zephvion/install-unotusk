Quick Start Guide

01

Deploy Host Server

On your server or workstation, install and run the Server Setup Wizard. Click Deploy to start the Docker services and initialize the database.

02

Share Endpoint URL

The wizard outputs your local IP endpoint (e.g. http://10.0.0.59:8000). Share this address with your engineering team.

03

Connect Client

Team members launch the Desktop Client on their machines, paste the server URL, and immediately begin querying the codebase.
