Install Unotusk MVP Client

Download the native employee desktop application to connect to your local Unotusk Server instance.

Linux

Ubuntu 22.04+ / Debian (x64)

Download .tar.gz v0.1.0 • 12MB

Windows

Windows 10 / 11 (x64)

Download .zip v0.1.0 • 15MB

Installation Instructions

1. Download the appropriate package for your operating system.

2. Extract the archive to your preferred location.

3. Run the application executable (`app` on Linux, `app.exe` on Windows).

4. On launch, enter your local Unotusk Server IP (e.g. `http://10.0.0.59:8000`) provided by your administrator.
