Quick Start

01 • ADMIN

Host Machine

Launch the Server Wizard on your host. Click deploy to start PostgreSQL 16, Redis, and FastAPI in Docker. Copy the emitted local address:

http://<local-ip>:8000
02 • TEAM

Client Connection

Launch the Desktop Client on your laptop and enter the Server IP provided by the admin. Verify connection:

curl http://<ip>:8000/api/v1/health
